## PickHue 3.0.0 — Dynamic Accent

PickHue now wears your colors. The entire UI — panel, toasts, menus, picker — derives its accent from your last-picked color, alongside a full UX overhaul.

**Free. No accounts. No tracking. Nothing leaves your machine.**

---

### What's new in 3.0.0

- **Dynamic accent** — the UI tints itself to your most recent pick (perceptually tuned in OKLCH, always legible). Gray picks keep the new coral default
- **Tinted chrome** — surfaces carry a whisper of your color in light and dark themes
- **Keyboard eyedropper** — `Alt+Shift+P` starts picking instantly (remappable, shown in settings); arrow keys nudge pixel-by-pixel, `Enter` picks
- **Smarter loupe** — the magnifier ring previews the color under the crosshair; zoom badge on the glass
- **Better save flow** — compact copy toast with a `+` save action that confirms with a ✓ and the palette name; hovering holds the toast open
- **Palette editor overhaul** — color count and Export up top, Duplicate action, drag reorder with a precise insertion indicator, keyboard reorder, live input validation
- **Shades & tints** — generate a 10-step ramp from any palette color; copy a step or add it in one click
- **Tailwind export** — copy any palette as a ready-to-paste `tailwind.config.js` snippet
- Reduced-motion support throughout

---

### Install (developer)

1. Download **pickhue-3.0.0.zip** below
2. Unzip the archive
3. Open `chrome://extensions` or `brave://extensions`
4. Enable **Developer mode** → **Load unpacked** → select the unzipped folder
5. Pin PickHue from the toolbar puzzle menu

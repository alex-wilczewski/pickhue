# Chrome Web Store — Detailed description (paste as-is)

PickHue is an elegant, in-page color picker. Pick any pixel with a magnifying loupe, keep your recent colors, and organize them into palettes that sync across your browsers. Free, no accounts, no tracking — nothing ever leaves your machine.

NEW IN 3.2 — NOTHING ASKED FOR
• No permission warning on install — PickHue no longer requests access to the sites you visit
• It can read a page only after you click the icon or press Alt+Shift+P, and that access ends when the tab navigates away
• The original PickHue green is back as the default accent
• Pick a near-white, near-black, or gray color and the interface retints to match it instead of staying on your last pick
• Accurate values over images, gradients, canvases, and SVG icons — where the rendered pixel is the truth, PickHue uses it
• A smoother loupe on pages playing audio or video, and calmer recapture while you scroll

NEW IN 3.1 — PRO TOOLS
• Color Card — tune any palette color with OKLCH sliders, browse 10-step shades & tints, stage several and add them in one tap
• Contrast checker — WCAG ratios with AAA/AA grades against white, black, and your palette, live while you tune
• Palette from this page — one click gathers a page's colors, grouped into backgrounds, text, and borders
• Area-average sampling — average 3×3 or 5×5 pixels for photos and anti-aliased edges
• Copy as anything — right-click a swatch to copy its value in any of seven color formats, from HEX to OKLCH

PICK
• Pixel-precise magnifying loupe with zoom, and a ring that previews the color under the crosshair
• DevTools-accurate values on solid fills and text
• Auto-copy on pick, in your preferred format
• Keyboard eyedropper — Alt+Shift+P starts picking instantly; arrow keys nudge pixel-by-pixel, Enter picks

ORGANIZE
• Recent colors with one-tap save to palettes (and undoable clear-all)
• Named palettes — rename, reorder by drag or keyboard, duplicate
• Import from Adobe .ase, CSS variables, or plain hex lists
• Export as hex list, CSS variables, Tailwind config, Adobe .ase, or JSON backup
• Palettes sync across your browsers via Chrome sync

DESIGNED, NOT JUST BUILT
• The whole interface tints itself to your last pick, tuned in OKLCH so every hue stays vibrant and legible
• Light, dark, and system themes
• Full keyboard support and reduced-motion friendly
• A UI that celebrates color — yours

Privacy: no analytics, no accounts, no remote code, and no network requests. Palettes and settings stay in your browser's sync storage. PickHue is open source under the MIT license: https://github.com/alex-wilczewski/pickhue

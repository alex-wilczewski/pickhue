## PickHue 3.1.0 — Pro Tools

Everything from the 3.0 Dynamic Accent redesign, plus a professional color toolkit: tune, grade, and extract.

**Free. No accounts. No tracking. Nothing leaves your machine.**

---

### What's new in 3.1.0

- **Color Card** — open any palette color: tune it with OKLCH sliders, browse its 10-step shades & tints, stage the ones you want, add them in one tap
- **Contrast checker** — WCAG ratios with AAA/AA grades against white, black, and the rest of your palette, live while you tune
- **Palette from this page** — one click gathers a page's colors, grouped into backgrounds, text, and borders; keep what you like, name it, save
- **Area-average sampling** — press S while picking to average 3×3 or 5×5 pixels (the reticle grows to show exactly what's sampled)
- **Copy as anything** — right-click a swatch for HEX, RGB, HSL, OKLCH, LCH, OKLAB, or HWB with live values
- **Clear recent colors** — hover the header, one tap, undoable from the toast
- The eyedropper opens instantly, and the loupe now clips at screen edges so you can pick the very last pixel

### From 3.0 (if you're coming from 2.x)

- **Dynamic accent** — the whole UI wears your last-picked color
- `Alt+Shift+P` keyboard eyedropper, pixel nudge with arrow keys, Enter to pick
- Rebuilt palette editor, compact save flow, Tailwind config export, reduced-motion support

---

### Install (developer)

1. Download **pickhue-3.1.0.zip** below
2. Unzip the archive
3. Open `chrome://extensions` or `brave://extensions`
4. Enable **Developer mode** → **Load unpacked** → select the unzipped folder
5. Pin PickHue from the toolbar puzzle menu
